# SudoDroid
#### The sudo binary in /system/bin for android

## Install 🚀
1. Download the [zip](https://github.com/axy0n-qli/SudoDroid/releases/download/1.0/sudodroid.zip)
2. Open your root manager (make sure you are a metamodule installed, otherwise install it's)
3. Flash the module and reboot
4. Now run in terminal or adb shell "sudo" (not in termux), you can also run action on your root manager for test
### Building from source 🤓
```bash
cd /tmp
git clone https://github.com/axy0n-qli/SudoDroid.git
cd SudoDroid && make
```
### Why?
I created this module for myself so I could easily use sudo in the actual Android terminal. That way I can keep my variables
